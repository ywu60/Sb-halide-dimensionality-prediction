Identify every non-standard abbreviation or symbol used in the compound's
reported formula (and cation formula, if present) that is NOT a standard
chemical element symbol.

Examples of symbols that need a definition: L, L', Cp, Cp*, bpy, phen, py,
dppe, or any other ligand/substituent shorthand the authors introduce.

You do not need to define universally standard solvate/solvent
abbreviations that chemists already recognize without paper-specific
context (thf, Et2O, MeOH, EtOH, DMF, DMSO, MeCN, H2O) — skip those unless
the paper gives them an unusual, compound-specific meaning.

For each symbol that does need definition, state exactly what it stands for
using only the wording/structure given in the evidence (e.g. the ligand's
full name or explicit formula), and cite the source IDs. If the formula
contains a symbol that needs definition but the evidence never defines it,
say so explicitly rather than guessing or omitting it — the reviewer needs
to know a symbol is undefined, not see it silently dropped.

Return only the required JSON schema. If no non-standard symbols are
present, return an empty list.
